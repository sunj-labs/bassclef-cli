# Risk ledger — bassclef migrate subcommand (v1)

## Purpose

This ledger pairs risks with compensators, build targets, and verification methods. Build wiring — tests carry `// @risk: R#` OR `// @rfc: <ID>` comments; commits carry `[risk: R#]` OR `[rfc: <ID>]` trailers; Step 7 signoff runs a grep audit and blocks if any row lacks matching evidence.

Pattern reuses scope-b1 discipline per bassclef-upstream#1420 (pre-mortem-to-compensator mapping as first-class /longrun output). This goal is the second bassclef-cli goal to dogfood the pattern.

## Klein pre-mortem framing

Imagine `bassclef migrate` ships as 0.1.1 and one week later Sam files an issue titled "bassclef migrate destroyed my customizations." What are the possible causes? Each ledger row below assumes that vivid failure and names its compensator.

## Lens summary — strongest per lens

- **Nygard** — R3 + R4 tie. R3 pins bulkhead ordering (manifest write last). R4 pins fail-fast on unknown state (no silent Path A fallback).

## Build wiring — how the ledger pins to code

Three touchpoints (same shape as scope-b1 per bassclef-upstream#1420):

1. **Test files carry `// @risk: R#` OR `// @rfc: <ID>` comments** naming which row they verify.
2. **Commits carry `[risk: R#]` OR `[rfc: <ID>]` trailers.**
3. **Step 7 signoff runs grep audit** against ledger:

   ```bash
   grep -rE "@(risk|rfc):" src/ | grep -oE "R[0-9]+|[A-Z][0-9]+" | sort -u > /tmp/tests-covered.txt
   git log feat/scope-e-migrate --grep -E "\[(risk|rfc):" | grep -oE "R[0-9]+|[A-Z][0-9]+" | sort -u > /tmp/commits-covered.txt
   grep -oE "^\| \*\*(R[0-9]+|[A-Z][0-9]+)\*\*" docs/pre-mortem-mappings/2026-08-30-migrate.md \
     | grep -oE "R[0-9]+|[A-Z][0-9]+" > /tmp/ledger-rows.txt
   diff /tmp/ledger-rows.txt /tmp/tests-covered.txt
   diff /tmp/ledger-rows.txt /tmp/commits-covered.txt
   ```

## Klein pre-mortem retrospective (dry-run)

Assume the migrate command shipped and one week later:

- **R2 fails** — Sam files "my settings.json got wiped." Compensator missing → hash comparison did not fire OR classifier treated `preserve` as `add`. Cure ships as ADR-008 amendment; regression test added; CHANGELOG apology.
- **R3 fails** — Sam ran migrate, laptop closed mid-run, retried, got a corrupted install. Compensator missing → manifest write happened before per-file writes completed. Cure: fix ordering; add fault-injection test.
- **R4 fails** — Sam had a partial install from a prior aborted operation; migrate proceeded with Path A and corrupted more state. Compensator missing → `detectLegacyManifest` returned a false positive. Cure: tighten detection; add strict-schema-validation test.
- **R6 fails** — init got a bugfix; migrate's Path B did not pick it up because Path B reimplemented init. Compensator missing → runPathB should have called `runInit`. Cure: refactor Path B; add integration test.

Each row's `verified` flip at Step 7 signoff means the test suite reproduces the failure AND the cure holds.
