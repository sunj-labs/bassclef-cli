## Four modules

| Module | Where | Owns | Depends on |
|---|---|---|---|
| **Catalog reader** | `scripts/prepublish-bundle-substrate.mjs` extension | Read manifest, validate schema, iterate entries, copy each to `dist/lite/<entry.path>` | `BASSCLEF_SIBLING_ROOT` env; `lite-manifest.json` present at sibling root |
| **Walker classifier** | `src/lib/copy-substrate.ts` extension | Route each dist file to a scope decision at init time; extend `decisionsForFile` for non-hook types | `classify()` from scope-router; ADR-057 destination-path table |
| **Init counter** | `src/commands/init.ts` extension | Compute + render per-type counts from `CopyResult.copiedEntries` | `CopyResult` type; existing banner code |
| **Preflight harness** | new `scripts/distribution-preflight.mjs` | Verify manifest ↔ bundle parity; block prepublish on drift | Catalog reader output; ledger row references |

## Module interfaces

### Catalog reader

**Input.** `<sibling>/lite-manifest.json` (v1.6.x compatible), `BASSCLEF_SIBLING_ROOT` env, `distRoot` target.

**Output.** `dist/lite/<entry.path>` for every manifest entry. Postflight count.

**Failure modes (@risk N1, RH).**
- Manifest missing at expected path → exit 4, `CopyFailure` kind `ManifestMissing`
- Schema major mismatch → exit 5, `CopyFailure` kind `SchemaIncompatible`
- Entry file missing at sibling → exit 4 with entry.path in stderr
- Path traversal in entry.path → exit 2, `PathTraversalRefused` from classify()

### Walker classifier

**Input.** `relPath`, current `scopeMap` (hooks only), `targetDir`, options.

**Output.** `ScopeDecision[]` per file. For non-hook types the walker routes to project scope via `classify({command: '$CLAUDE_PROJECT_DIR/' + relPath}, opts)`.

**Path routing (@risk HW — pinned in ADR-057).**

| Bundle path prefix | Target class | Scope | Rationale |
|---|---|---|---|
| `.claude/hooks/*.sh` | hook (declared) | per scopeMap (existing) | 1.0.4 dual-scope logic (unchanged) |
| `.claude/hooks/*.sh` (undeclared) | hook (helper/fragment) | dual (user + project) | 1.0.4 dual-scope (unchanged) |
| `.claude/skills/*/SKILL.md` | skill | project | co-located with adopter repo |
| `.claude/rules/*.md` | rule | project | co-located; agent reads via additionalDirectories |
| `.claude/agents/*.md` | agent | project | co-located |
| `.claude/luminaries/*.md` | luminary | project | co-located |
| `lib/*.sh` | lib | project | co-located; hooks source via `$CLAUDE_PROJECT_DIR/lib/*` |
| `standards/*` | standard | project | co-located |
| `architecture/decisions/ADR-*.md` | adr | project | co-located |
| `presence/install/*` | template | project | co-located; install helpers |

### Init counter

**Input.** `CopyResult.copiedEntries` (each entry carries `path` + `scope`).

**Output.** Banner lines per type:
```
bassclef init: Installed 24 of 24 hooks (lite tier). 22 in <repo>/.claude/hooks, 2 in ~/.claude/hooks.
bassclef init: Installed 40 skills, 63 rules, 4 agents, 32 luminaries under <repo>/.claude/.
bassclef init: Installed 30 libs, 6 ADRs, 5 templates under <repo>/.
```

**Refused-count line (@risk L1, L3).**
```
bassclef init: 0 files refused (path collision).  <-- happy path
bassclef init: 3 files refused (path collision). Use --force to overwrite.
```

### Preflight harness

**Input.** Manifest path, dist root, prior-tag baseline (optional).

**Output.** PASS / BLOCK with structured stderr per failure class.

**Checks (Steps 1-6 of standards/distribution-preflight.md; Step 7 substrate cure lands the standard):**
1. Manifest present + schema-major matched
2. Every entry.path exists in `dist/lite/`
3. Every file in `dist/lite/` traces to a manifest entry OR the allowlist (settings.json, wiring manifest, package templates)
4. File-count delta vs prior-tag baseline within tolerance
5. Cold-adopter smoke rides Step 10 (out of prepublish scope; in ship-gate scope)
6. ADR-057 alignment: every type in the destination-path table has entries in the manifest
