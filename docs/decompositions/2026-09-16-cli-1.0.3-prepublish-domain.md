## Patterns instantiated

- **@pattern `patterns/code/gof/template-method.md`** on `copyHookTreeRecursive` — the walk shape (enter → decide entry type → recurse or copy → exit) is the template; specific handling per entry type is the variation
- **@pattern `patterns/code/nygard/fail-fast.md`** on `assertDeclaredCommandsHaveBinaries` — postflight is the circuit breaker that trips before `npm pack` sees a broken output
- **@pattern `patterns/code/saltzer-schroeder/complete-mediation.md`** on the symlink check — every entry mediated; no bypass

Annotation lands in code as JSDoc comment on the function definition per `.claude/rules/pattern-annotation.md`.

## Migration approach

Split into two commits so the RED → GREEN handoff is auditable:

1. **RED commit** — add failing tests + fixture, keep old `copyHookBinaries` in place. Suite fails at the new tests.
2. **GREEN commit** — swap `copyHookBinaries` for `copyHookTreeRecursive` + `assertDeclaredCommandsHaveBinaries`. Suite passes. Version bump to 1.0.3.

## Anti-patterns to avoid

- **Don't reuse the old function name** — the shape changes; rename so any external caller (there isn't one, but grep proves it) breaks visibly
- **Don't add a "legacy fallback" path** — YAGNI; the new shape is a superset of the old behavior
- **Don't grow the postflight** with `install-class` header checks — that's upstream's responsibility
