# v1.9.14 — housekeeping on our build machines

**Released** 2026-10-10 · **Bassclef substrate** `v1.9.3`

## What this means for you

Nothing. This release changes how our own tests run and nothing about the package you install.

We updated the versions of the build tools our tests use, before the old ones stopped being supported.

## What changed

- Build tool versions updated across all five of our test workflows.
- Tests now run on a pinned operating system version instead of whichever one was newest.

## Do you need to do anything?

No. The package is identical to v1.9.13 in everything you can see.
