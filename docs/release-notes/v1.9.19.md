# v1.9.19 — four fixes from watching a real first install

**Released** 2026-10-18 · **Bassclef substrate** `v1.11.1`

## What this means for you

Someone installed bassclef from scratch on a clean machine while we watched. Four things went wrong. All four are fixed here.

The most annoying one: your first `git push` after installing would be blocked by 72 complaints about bassclef's own shell scripts. Not your code. That no longer happens.

## What changed

- Your first push is no longer blocked by findings in files bassclef installed. The check now knows which files it wrote. It still checks yours.
- The sign-in check works on a Mac without extra tools installed.
- Scheduling auto-save works without needing a second copy of bassclef next to your project.
- The Concise prompt now explains what it does before asking, and defaults to no. Turning it on stays a deliberate choice.

## Do you need to do anything?

No.

## Notes

All four were filed and fixed upstream in one cycle. This version carries them into the package you install.
