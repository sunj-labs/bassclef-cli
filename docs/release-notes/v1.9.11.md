# v1.9.11 — six fixes to the planning commands

**Released** 2026-10-07 · **Bassclef substrate** `v1.8.0`

## What this means for you

Six commands that stopped or gave you bad output now work. All six were reported by people using the free tier.

## What changed

- `/build` warns instead of refusing when your project has no hosting set up. You can still plan work on a project you have not deployed.
- A check stopped blocking work when a goal had no parent goal.
- `/interpret-input` fills in two fields it used to leave empty, so the commands that read its output no longer break.
- `/launch` no longer leaks template boilerplate into your plan.
- `/launch` tells the difference between a new project and a redesign, and asks for less when the project is new.

## Do you need to do anything?

No.
