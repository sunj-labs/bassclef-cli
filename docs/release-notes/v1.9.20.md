# v1.9.20 — bassclef init says hello properly

**Released** 2026-11-04 · **Bassclef substrate** `v1.11.1`

## What this means for you

When you run `bassclef init`, it now shows the bassclef mark before telling you it is ready. That is the whole change. Nothing works differently.

## What changed

- `bassclef init` prints the bassclef mark above "Bassclef is ready."
- On a narrow window it prints two lines of text and skips the mark. A mark split across lines looks like something broke, so it is better left out.
- `bassclef init --json` is unchanged. Anything reading that output sees exactly what it saw before.

## Do you need to do anything?

No.

## Notes

The mark uses four characters that come with every Mac and Linux terminal. You do not need to install a font.

An earlier draft used Braille characters, which draw curves better. Menlo and SF Mono carry none of them, so that draft would have shown empty boxes on most terminals. The design notes record why, so nobody tries it again.
