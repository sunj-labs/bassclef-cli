# v1.9.16 — the Concise prompt, and a same-day fix to it

**Released** 2026-10-13 · **Bassclef substrate** `v1.10.1`

## What this means for you

`/onboard-repo` now asks whether you want Anthropic's Concise output style turned on. Answer yes and it edits your Claude Code settings, keeping every other setting you already had.

The first version of this broke. The helper file it needed was installed to the wrong place, so anyone answering yes hit a missing-file error. A peer caught it ten minutes after release and this version carries the fix.

## What changed

- New prompt in `/onboard-repo` for the Concise output style. Yes, no, or skip.
- The helper file now installs where the prompt looks for it.
- New measuring tools that track how plainly bassclef writes. Off unless you turn them on.

## Do you need to do anything?

No. If you installed v1.10.0 of the substrate directly and answered yes to the Concise prompt, update — that is the version with the broken path.

## Notes

The new measuring tools are off by default. Set `prose_discipline.scorer_track` in `.claude/bassclef-configs.jsonc` to turn them on.
