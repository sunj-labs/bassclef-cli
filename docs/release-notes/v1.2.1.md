# v1.2.1 — smoke bootstrap fixes + bassclef v0.46.0 substrate

**One-line.** First widely publicized release. Ships four smoke bootstrap fixes plus bassclef v0.46.0, including the dispatcher cure this project filed as cli#140.

## What is bassclef-cli?

`@thebassclef/lite` is the free-tier CLI for the bassclef substrate. Bassclef ships skills, rules, hooks, and luminaries. Together they pin discipline at decision boundaries in Claude Code sessions. Install once. Run `bassclef init` in a project. The substrate wires itself.

## What ships in 1.2.1

### Bundled substrate: bassclef v0.46.0

The bundle steps from v0.45.0 to v0.46.0. What lands:

- **Dispatcher probes `$CWD/lib/`** (cli#140, bassclef-upstream PR #1796). The substrate dispatcher now checks `$CWD/lib/` as the second probe path when it resolves `bassclef-dir-resolver.sh`. Cli sessions started outside `~/src/sunj-labs/` no longer hit resolver-missing errors. This project filed the cure upstream; it landed and rides down through the substrate bundle.
- **Pre-commit auto-regen manifest hook** (bassclef-upstream #1752). Local commits that touch lite-tier source now regen the manifest automatically. Adopters stop hitting "manifest drift" CI failures from missed regen steps.
- **Workflow-metrics library** (bassclef-upstream #1307). Module B4 measurement infrastructure. Reads GitHub Actions run JSON and emits per-workflow wall clock. No adopter action needed; future perf work rides on this.
- **New luminaries**: david-farley plus jez-humble. Both live under `.claude/luminaries/` after init.

### Smoke bootstrap fixes

Cold-adopter runs from bassclef-cli#147 surfaced four rough edges. All four ship in 1.2.1.

- **`cd ~` leads the one-liner** (cli#146, cli#144). The runbook one-liner now leads with `cd ~`. Adopters land in their home directory. Sister guard: reset flow can delete the current working directory. Bootstrap warns on that class.
- **Smoke label auto-create plus `gh` error surface** (cli#141). Release label derives per release. Script creates it if missing instead of failing silently. `gh` CLI errors now surface to the operator rather than being swallowed.
- **`gh` account pre-flight** (cli#143). Runbook asserts `kingofrock` is the active `gh` account before hitting `sunj-labs`. Catches account authorization failures before the smoke starts.
- **Step 5 timeout 30s → 120s** (cli#138). Docs match the script default. Slower cold-adopter hardware needed the headroom.

## Install

```
npm install -g @thebassclef/lite@latest
bassclef --version   # → 1.2.1
```

Wire the substrate into a project:

```
cd ~/your-project
bassclef init
```

Pick up a substrate refresh in an existing project:

```
bassclef sync
```

## Migration

No migration required. PATCH bump.

Existing adopters re-running `bassclef init` (or a fresh `npm install -g @thebassclef/lite@latest`) pick up the v0.46.0 substrate bundle.
