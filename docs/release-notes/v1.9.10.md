# v1.9.10 — seven fixes for your first five minutes

**Released** 2026-10-05 · **Bassclef substrate** `v1.7.1`

## What this means for you

Seven things that went wrong in the first five minutes of using bassclef now work. Most of them hit people on a Mac, because macOS ships an old version of bash.

Nothing you have to do. Install or update and the fixes are there.

## What changed

- `/onboard-repo` no longer fails on macOS. It used a bash feature that the version Apple ships does not have.
- `/longrun` runs its flow correctly.
- `/extract-intent` works.
- `/autonomous` has instructions for the free tier, so it no longer tells you to use something you do not have.
- `/launch`, `/build`, and `/deploy-prod` handle a project with no hosting set up.
- A tool that checks what your machine can do stopped reporting the wrong answer.

## Do you need to do anything?

No. `npm install -g @thebassclef/lite` picks it up.

## Notes

Two problems stayed open after this release — `/launch` still shipped one old template field, and a check that was supposed to guard architecture edits was not switched on. Both tracked as cli#322 and cli#329.
