# v1.9.18 — six first-run problems fixed

**Released** 2026-10-18 · **Bassclef substrate** `v1.11.0`

## What this means for you

Six things that tripped people up on their very first run now work. They came from watching real first installs.

This is also the first version that actually reached npm carrying this substrate. v1.9.17 was tagged but its publish failed. See those notes.

## What changed

- `/onboard-repo` checks more up front — that the CLI is there, that you are signed in, that git knows who you are. It checks before doing anything, not halfway through.
- `/onboard-repo` offers a new name when the repo name you want is taken, instead of stopping.
- `/onboard-repo` checks whether you can make a private repo before it tries.
- Prompts now say what you get before asking you to decide.
- A new check scans shell scripts before you push and blocks real problems.
- A slow step that took over two minutes now finishes in under a second.

## Do you need to do anything?

No.

## Notes

The publish needed one more fix to get through: our leak scanner flagged `you@example.com` in a bundled file. That is the address git's own docs use as an example. We allowed it in that one file and left the scanner strict everywhere else.
