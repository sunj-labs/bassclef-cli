# v1.9.23 — the brass prints, on a grid that fits

**Prepared** 2026-11-08 · **Bassclef substrate** `v1.11.1`

## What this means for you

Run `bassclef init` and you now see a brass wordmark on a clean grid.
Before this release it was plain grey text. It sat hard against the
install log above it, and the command list ran together underneath.

Two lines also used to break in the middle of a sentence if your
terminal was the standard 80 columns. They fit now.

If you are already set up, you need to do nothing. This changes what
`bassclef init` prints and nothing else.

## What changed

**The brand colour appears.** We wrote a brass chip into 1.9.22 and
never called it. The code was there. It had tests. Nothing used it. It
prints now. We draw the wordmark in the same brass, so the two read as
one mark instead of a grey logo with a coloured label beneath it.

**The output has a shape.** Everything the tool says about itself steps
in two columns from the install log. That step separates the three
parts of the screen: what we installed, who we are, what to type next.
A blank line now sits between the log and the mark.

**The three commands line up.** `claude` and `/riff` had a blank line
above them. `/launch` and `/build` did not. All three match now, so the
list scans as a list.

**Nothing breaks in the middle of a sentence.** Two lines ran to 94 and
93 characters. A default terminal is 80. We split both at the sentence
break. Our longest line is now 71 characters. No wording changed.

**Colour turns itself off when it should.** Pipe the output to a file,
set `NO_COLOR`, or use a terminal that cannot show colour, and you get
clean text with no escape codes in it. Set `FORCE_COLOR` to turn colour
back on in a pipe.

## If your terminal is narrow

Below 42 columns we drop the wordmark and print the name, the version
and the tagline on their own. A wordmark cut off mid-letter looks
broken, and nothing is.

## Fixed

- The brass chip prints. It shipped in 1.9.22 with no caller.
  ([#484](https://github.com/sunj-labs/bassclef-cli/issues/484))
- The tool reads your environment to decide about colour instead of
  assuming.
  ([#484](https://github.com/sunj-labs/bassclef-cli/issues/484))
- `scripts/publish-gate.sh off` works. This is our own release tooling.
  It does not ship in the package you install.
  ([#481](https://github.com/sunj-labs/bassclef-cli/issues/481))

## Known, and not fixed here

We still pin the bundled framework files at `v1.11.1` from 2026-10-18.
This release carries the same framework content that 1.9.22 did.
Tracked at
[#482](https://github.com/sunj-labs/bassclef-cli/issues/482).
