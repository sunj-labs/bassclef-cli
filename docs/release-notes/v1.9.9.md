## Cures inherited — per Kunal finding

Each cure is authored upstream; cli ships the bundle. See upstream PR body for full implementation detail — bassclef-upstream#1523.

### #1 Trace-log privacy leak (upstream PR #2041)

- **Symptom (what Kunal saw):** `trace.log` files committed to his adopter repo carried `/Users/kunal/...` paths; auto-save push surfaced these to git history.
- **Root cause (upstream):** 3 compounding gaps — adopter template `.gitignore` lacked `docs/sdlc-traces/`; `trace-helper.sh` logged absolute paths; `save-state.sh` ran no leak check before commit.
- **Fix (bundled in v1.7.0):** `trace_log()` now strips repo root via `_trace_repo_root()` helper; `lib/identifier-leak-check.sh` sources before `git commit` in `save-state.sh`; shipped `.gitignore` adds `docs/sdlc-traces/`.
- **cli verification:** `grep -c "sanitize\|/Users/" dist/lite/.claude/hooks/trace-helper.sh` returns > 0 after bundle rebuild. `ls dist/lite/lib/identifier-leak-check.sh` resolves.

### #2 /build Phase 1 awk range (upstream PR #2043)

- **Symptom:** `/build` on any template-authored spec returned zero steps.
- **Root cause:** awk range `/^## Steps enumerated/,/^## /` closed on its own start line because `^## ` matches `^## Steps enumerated`.
- **Fix (bundled in v1.7.0):** flag-based extractor accepts both `Steps` and `Workunits` heading forms during ADR-040 D1 grace window.
- **cli verification:** `grep -c "Steps\\|Workunits" dist/lite/.claude/skills/build/SKILL.md` > 0 after bundle rebuild.

### #3 Template heading mismatch (upstream PR #2043)

- **Symptom:** Combined with #2 — template said `## Workunits enumerated` while SKILL expected `## Steps enumerated`.
- **Root cause:** ADR-040 D1 renamed WU → step in prose but missed `templates/spec-template.md`.
- **Fix (bundled in v1.7.0):** template heading renamed to `## Steps enumerated`; SKILL regex accepts both forms during grace window.
- **cli verification:** `grep -c "## Steps enumerated" dist/lite/templates/spec-template.md` > 0 after bundle rebuild.

### #4 SKIP_* env-reach override recipes (upstream PR #2042)

- **Symptom:** `SKIP_FOO=1 git commit ...` recipe from BLOCK banners did not bypass the hook.
- **Root cause:** PreToolUse Bash hooks run in Claude Code's process env; inline `SKIP_FOO=1 <cmd>` sets the var in git's subshell, not the hook's env.
- **Fix (bundled in v1.7.0):** `lib/skip-env-inline-check.sh` parses `tool_input.command` for inline prefix + falls back to process env. Applied across 6 PreToolUse Bash hooks.
- **cli verification:** `ls dist/lite/lib/skip-env-inline-check.sh` resolves after bundle rebuild.

### #5 Shipped example path triggered own CCF-3 guard (upstream PR #2042)

- **Symptom:** Operator-path guard fired on a verbatim `/Users/kunal/...` example in a shipped install guide.
- **Root cause:** Example path in `presence/install/schedule-auto-save.taskscheduler.md` matched the CCF-3 regex. The guard fired correctly; the shipped content was the defect.
- **Fix (bundled in v1.7.0):** rewrote the example as prose — removed the literal `/Users/<name>/` pattern.
- **cli verification:** `grep -c "/Users/" dist/lite/presence/install/schedule-auto-save.taskscheduler.md` returns 0 after bundle rebuild.

### #6 zsh PATH kill (upstream PRs #2043 + #2045)

- **Symptom:** Any state-reading skill failed silently (commands not found) when `lib/state.sh` sourced from zsh.
- **Root cause:** zsh ties `path` and `PATH` as linked variables. `local path="..."` wiped PATH for function scope under zsh (invisible under bash).
- **Fix (bundled in v1.7.0, two upstream PRs):**
  - PR #2043: renamed `local path=` → `local p=` across 7 functions in `lib/state.sh`
  - PR #2045: closed the full class across 10 more lib files (24 more occurrences)
- **cli verification:** `grep -rn "local path=" dist/lite/lib/*.sh` returns 0 after bundle rebuild.

### #9 Free-tier GitHub branch-protection docs (upstream PR #2044)

- **Symptom:** `/onboard-repo` Phase 1.2 hit HTTP 403 on free-tier private repos with no fallback path documented.
- **Root cause:** SKILL assumed `gh api` always succeeds (authored against Pro-tier accounts).
- **Fix (bundled in v1.7.0):** three paths documented before the API call (make public, upgrade, skip local); fallback writes `.claude/onboard-notes.md` marker.
- **cli verification:** `grep -c "upgrade\\|public\\|local-only" dist/lite/.claude/skills/onboard-repo/SKILL.md` > 0 after bundle rebuild.
