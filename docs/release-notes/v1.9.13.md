# v1.9.13 — `bassclef init` tells you what to try next

**Released** 2026-10-10 · **Bassclef substrate** `v1.9.3`

## What this means for you

`bassclef init` used to end by printing how many skills and rules it installed. Those numbers did not help you do anything.

Now it ends with one line proving bassclef is running, and three commands worth trying: `/riff`, `/launch`, `/build`. You can be doing something useful in about five minutes.

The counts are still there if you want them. Run `bassclef init --verbose`.

## What changed

- `bassclef init` ends with a short block naming three things to try.
- Catalog counts moved behind `--verbose`.
- The hook banner and the refused-file count print as before.

## Do you need to do anything?

No. If you had scripts reading the count lines, add `--verbose`.
