## State diagram

```mermaid
stateDiagram-v2
  [*] --> BuildStart : npm publish triggers prepublish
  BuildStart --> ManifestLoad : loadWiringManifest
  ManifestLoad --> ManifestBad : parse fail OR missing
  ManifestBad --> [*] : fail(reason)
  ManifestLoad --> TierFilter : filterHooksByTier('lite')
  TierFilter --> SettingsWrite : emitDistLiteSettings
  SettingsWrite --> TemplatesCopy : copyDistTemplates
  TemplatesCopy --> ManifestCopy : copyWiringManifestIntoDist
  ManifestCopy --> HookTreeCopy : copyHookBinaries (RECURSIVE, new)
  HookTreeCopy --> HookTreeMissing : sibling hooks dir absent
  HookTreeMissing --> [*] : fail(remediation)
  HookTreeCopy --> HookTreeEmpty : zero *.sh under sibling
  HookTreeEmpty --> [*] : fail(pre-v0.42.0)
  HookTreeCopy --> HookTreeSymlink : lstat detects symlink
  HookTreeSymlink --> [*] : fail(refusing to follow)
  HookTreeCopy --> HookTreeIOError : read or write fails
  HookTreeIOError --> [*] : fail(path + errcode)
  HookTreeCopy --> Postflight : all copies OK
  Postflight --> CommandMissing : declared command lacks binary
  CommandMissing --> [*] : fail(missing name)
  Postflight --> BuildOK : every declared command has binary
  BuildOK --> [*] : return hookCount to caller; npm pack proceeds
```

## Sequence diagram — happy path

```mermaid
sequenceDiagram
  participant NPM as npm publish
  participant PPS as prepublish-bundle-substrate.mjs
  participant SIB as SiblingHookTree (dist/lite/.claude/hooks/)
  participant CLI as CliDistTree (dist/lite/.claude/hooks/)
  participant PACK as npm pack

  NPM->>PPS: prepublishOnly fires
  PPS->>SIB: readdirSync (top-level)
  SIB-->>PPS: 24 files + 1 dir (session-reflection.d/)
  loop for each entry
    alt regular file
      PPS->>SIB: readFileSync(entry)
      SIB-->>PPS: content + mode
      PPS->>CLI: writeFileSync(entry, content, mode)
      PPS->>CLI: chmodSync(entry, 0o755) if executable
    else directory
      PPS->>CLI: mkdirSync(dir)
      PPS->>SIB: readdirSync(dir)
      SIB-->>PPS: 2 fragment files
      Note over PPS,SIB: recurse into subdirectory
    else symlink
      PPS-->>NPM: fail(refusing to follow)
    end
  end
  PPS->>PPS: postflight — walk declared commands
  loop for each command in filteredSettings
    PPS->>CLI: existsSync(command leaf name)
    alt exists
      CLI-->>PPS: OK
    else missing
      PPS-->>NPM: fail(missing)
    end
  end
  PPS-->>NPM: return {hookCount, copiedHookCount}
  NPM->>PACK: proceed with tarball
```

```mermaid
    PPS->>CLI: existsSync(ghost-hook.sh)
    CLI-->>PPS: false
  end
  PPS-->>PPS: fail("postflight: settings.json declares ghost-hook.sh but no matching binary in tree")
```

## Interaction rules

- **No prompts.** Prepublish is batch. If a decision would need input, `fail()` instead.
- **All errors carry the offending path** plus a one-line remediation
- **Success is quiet.** One-line summary at the end: `dist/lite/.claude/hooks/ received 26 files (24 top-level + 2 fragments)`
- **No retry.** Fail once, exit. `npm publish` will not proceed.
