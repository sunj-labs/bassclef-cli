## What ships

Cli 1.0.1 published as `@thebassclef/lite@1.0.1` to npm.

Behavior delta vs 1.0.0:

1. **Bump upstream tag pin to v0.40.0** in `package.json` `bassclef.upstream_tag` + `dist/lite/.bassclef-source.json` `source_ref`.
2. **Extend `src/lib/copy-substrate.ts` walker** with per-scope routing:
   - Hook files (`dist/lite/.claude/hooks/*.sh`) route per settings.json command prefix.
   - `$HOME/...` → `~/.claude/hooks/<name>.sh` (user scope).
   - `$CLAUDE_PROJECT_DIR/...` → `<adopter-repo>/.claude/hooks/<name>.sh` (project scope).
   - Non-hook files stay project-scope per cli 1.0.0 behavior.
3. **Preserve executable bit** — walker sets mode `0755` on every copied `.sh` file. Skips chmod on `win32` with INFO stderr note.
4. **Extend `writeSafely` symlink refusal to user-scope** — refuses to overwrite a symlink at either `~/.claude/hooks/x.sh` or `<repo>/.claude/hooks/x.sh`. Existing project-scope refusal unchanged.
5. **Banner reports honest count** — `N of M hooks armed (<tier> tier)` when copied count differs from declared count; `N hooks armed (<tier> tier)` when they match.
6. **Init manifest extended** with `scope: user | project` field per entry.
7. **Retire placeholder regex stopgap** — remove `[Repo name]` + `<tier>` fallback shapes from `makePlaceholderTransform` in `src/commands/init.ts`. Upstream dist-templates use canonical `[REPO_NAME]` + `[TIER]` shapes only (per closed bassclef-cli#77).
8. **Exit codes extended** per ADR-002 §Amendment:
   - Existing 0, 1, 2, 3, 4, 5 preserved.
   - Extension 5b (unknown scope prefix) → exit 5.
   - Extension 1a (`$HOME` unset) → exit 1.
   - Extension 1c (sudo bypass with `$HOME=/root`) → exit 1.
   - Extension 6e (path traversal) → exit 2.
   - Extension 8a (banner count mismatch) → exit 2.
9. **Publish workflow unchanged.** Trusted-publisher OIDC + provenance per cli 0.0.2 shape.

## What does NOT ship

- No cli-side composition of settings.json. ADR-055 D1 preserved.
- No new tier bundles. Standard + ultra reservations stay open per whereami L125-127.
- No cli 1.1.0 features (retry on partial copy, `--refresh-user-hooks` flag). Deferred to future release.
- No changes to `bassclef sync`. User-scope hooks copied by init are NOT sync-managed — adopter owns them. `bassclef init --force` refreshes them.

## Patterns used

Per `.claude/rules/pattern-annotation.md` — every conscious pattern instance carries `@pattern` in the source code.

| Class / interface | Pattern (source in bassclef-upstream catalog) | Reasoning |
|---|---|---|
| `ScopeRouter` | GRASP Information Expert + GoF Strategy (`patterns/code/gof/strategy.md`) | Per-prefix routing rule is a strategy family; extensible via new strategy on new prefix |
| `ExecutableBitEnforcer` | GRASP Information Expert | Sole owner of executable-bit rule + platform variation |
| `writeSafely` extension | GRASP Information Expert + Fowler Special Case (`patterns/code/fowler/special-case.md`) | Typed `WriteError` failures carry remediation strings |
| `InitDispatcher` | GRASP Controller (Larman) | First class receiving `bassclef init` system event |
| `InitWalker` | GRASP Coordinator + GoF Iterator (`patterns/code/gof/iterator.md`) | Composes ScopeRouter + ExecutableBitEnforcer + writeSafely; walks bundle tree |
| `CopyResult`, `HookCommand`, `ScopePrefix`, `ScopeDecision` | GoF Value Object (`patterns/code/gof/value-object.md`) | Immutable data carriers; equality-by-value |
| Validation chain inside `ScopeRouter` | GoF Chain of Responsibility (`patterns/code/gof/chain-of-responsibility.md`) | Prefix inspection → env resolution → containment check; each may throw + short-circuit |
| WiringManifest read | Fowler Registry (`patterns/code/fowler/registry.md`) | Single-lookup point per walker run |

## Acceptance

Every row below is a testable postcondition. Step 10 Tier 0 RED harness pins each one before the walker touches source code.

- [ ] `package.json` `bassclef.upstream_tag` equals `v0.40.0`.
- [ ] `dist/lite/.bassclef-source.json` `source_ref` equals `v0.40.0` (regenerated by prepublish script).
- [ ] `ScopeRouter` class exists at `src/lib/scope-router.ts`. Every public method + failure kind matches the interface in the GRASP decomposition. All Tier 0 tests GREEN.
- [ ] `ExecutableBitEnforcer` class exists at `src/lib/executable-bit-enforcer.ts`. Windows path emits INFO stderr note. POSIX path sets mode `0755`. All Tier 0 tests GREEN.
- [ ] `writeSafely` accepts user-scope targets (either via new options arg OR sibling function per Step 6 walker impl decision). Symlink refusal works at `~/.claude/hooks/*` targets the same way it works at project-scope targets.
- [ ] `copySubstrate` walker classifies every hook file via `ScopeRouter` and routes accordingly. Every settings.json command with `$HOME/` prefix lands in `~/.claude/hooks/`; every command with `$CLAUDE_PROJECT_DIR/` prefix lands in `<targetDir>/.claude/hooks/`.
- [ ] Every copied `.sh` file has mode `0755` on POSIX platforms (validated via `statSync(path).mode & 0o111`).
- [ ] Banner outputs `24 hooks armed (lite tier)` on a happy path (matching declared count in v0.40.0 settings.json).
- [ ] Banner outputs `N of M hooks armed (lite tier)` and exit 2 when copied < declared.
- [ ] `.bassclef/init.manifest.json` includes per-entry `scope: user | project` field.
- [ ] Second `bassclef init` run without `--force` refuses every user-scope AND every project-scope overwrite; exit 2.
- [ ] Placeholder regex stopgap removed from `makePlaceholderTransform`. Only `[REPO_NAME]`, `[ISO_TIMESTAMP]`, `[TIER]` patterns remain.
- [ ] `bassclef init` on a cold-adopter macOS profile with `npm install @thebassclef/lite@1.0.1` produces zero hook-not-found errors on Claude Code session-start.
- [ ] Full Tier 0 suite GREEN. Any regression from cli 1.0.0 behavior is a spec violation, not a feature.
- [ ] `@thebassclef/lite@1.0.1` published to npm via trusted-publisher workflow with provenance attestation.

## Out of scope

- `bassclef doctor` self-heal command — deferred; separate ticket.
- `--refresh-user-hooks` flag — deferred; adopter UX pass in a later release.
- Adopter migration from prior cli versions with pre-existing user-scope hooks — refuse-and-report on Ext 6c is the current path; a future release may add a `--force-user-scope` variant.
- Retry on partial copy (Nygard sister risk) — walker exits 2 on any failed copy; retry is the adopter's job (rerun with `--force`).
- Handling of a third scope prefix in a future upstream release — walker throws `UnknownScopePrefix` per Ext 5b; adopter must upgrade cli.

## Risk ledger v1 → engineering fold map

Per Klein Step 4, every top-5 risk lands as a specific engineering action. Ledger v2 in Step 9 folds RFC findings.

| Risk # | Risk | Ledger lens | Engineering fold |
|---|---|---|---|
| 1 | S2 — user-scope writes do not refuse symlinks | Saltzer-Schroeder | Extend `writeSafely` for user-scope OR add `writeSafelyUserScope` (Step 6 walker impl picks one); Tier 0 test asserts symlink at `~/.claude/hooks/x.sh` → `WriteError.SymlinkRefused` |
| 2 | S3 — executable bit missing after copy | Saltzer-Schroeder | New `ExecutableBitEnforcer` class; walker calls `setExecutable(target)` after every `.sh` write; Tier 0 test asserts `statSync().mode & 0o111 !== 0` on POSIX; INFO stderr note on `win32` |
| 3 | N5 — banner count claim not verified | Nygard | Walker's `CopyResult.copied.filter(isHookFile)` produces the copied count; InitDispatcher compares vs settings.json declared count; banner + exit 2 on mismatch |
| 4 | N2 + S1 — `$HOME` unset OR sudo bypass | Nygard + Saltzer-Schroeder | `ScopeRouter.classify` throws `EnvironmentIncomplete` (env unset) or `SudoBypassRefused` (`HOME=/root` with `--allow-root`); Tier 0 tests cover both branches |
| 5 | F6 — manifest omits user-scope hooks | Feathers | Extend `ManifestEntry` type with `scope: "user" \| "project"` field; walker records per-scope in the result; `writeManifest` propagates the field; Tier 0 test asserts round-trip |
