### F-17 — Root-doc detection heuristic may miss SECURITY.md if operator-authored

- **Severity.** AMBER
- **Lens.** Ishikawa Man + Hyrum
- **Where.** `src/commands/init.ts` L369-374
- **My claim.** The root-doc heuristic `!includes('/') && /^[A-Z]/.test(entry.path)` catches `AGENTS.md`, `README.md`, `CLAUDE-lite.md`, `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`. But if manifest ships a new root-doc named `agents.md` (lowercase), it won't count as a root-doc.
- **Evidence.** Manifest v1.6.1 has 6 root-doc entries — all start with uppercase. Real risk = low. Future-proofing risk = medium.
- **Why the evidence supports the claim.** Hyrum: any adopter piping through `grep '(N) root-docs'` gets a stable contract with 1.6.x. Ledger row F-17 for future manifests that use lowercase.
- **Cure.** Refactor to path-set membership check against ADR-057 D1 root-doc set. Deferred to 1.1.1+ if manifest ships new root-doc with lowercase name.
