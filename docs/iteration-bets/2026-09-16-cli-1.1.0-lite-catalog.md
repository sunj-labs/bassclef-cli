## Problem

Cold adopters on `@thebassclef/lite@1.0.0` through `@1.0.4` get a hooks-only substrate. The bundle ships zero skills, zero rules, zero agents, zero luminaries. Sam's magic demo path (`/onboard-repo --greenfield-from-intent`) stops at the first sub-skill dispatch. The npm package promises a lite tier and delivers only its hook layer. bassclef-upstream tags 40 skills, 63 rules, 32 luminaries, and 4 agents as `tier: lite`. The `lite-manifest.json` catalogs 292 entries at v1.6.1 (2026-09-15). None of them reach adopters via npm.

## Value prop

Cold adopters install `@thebassclef/lite@1.1.0` once. They get the full lite catalog on disk — 40 skills, 63 rules, 32 luminaries, 4 agents, hooks, libs, ADRs, presence templates. Sam's magic demo chain runs end-to-end. No sync-clone needed. The npm package finally delivers what the tier tag promised.

## Solution shape

1. Prepublish reads `lite-manifest.json` from the bassclef-upstream sibling checkout at build time.
2. For every entry in the manifest, copy `<sibling>/<entry.path>` to `dist/lite/<entry.path>`.
3. Init walker routes non-hook types (skill / rule / agent / luminary / lib / adr / standard / template) to project scope, with mediation preserved.
4. Init banner reports counts per type alongside hooks.
5. Tier 0 tests pin the 292-entry invariant.
6. Cold-adopter walking skeleton smoke exercises one skill, one rule, one agent presence, one luminary reference.
7. Distribution pre-flight discipline lands at bassclef-upstream as a substrate cure that rides alongside code.
