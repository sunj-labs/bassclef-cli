# Goal — cli 1.0.3 prepublish recursive hook copy

## Problem

Cli 1.0.2 tarball ships 24 hook files but is missing `trace-helper.sh` and `session-reflection.d/` — files that bundled hooks source at runtime. Cold-adopter-1 smoke on live 1.0.2 hit the exact 1.0.1 crash class at first `claude` session: `session-reflection.sh: line 38: /Users/cold-adopter-1/.claude/hooks/trace-helper.sh: No such file or directory`. Adopters cannot boot Claude cleanly against 1.0.2.

## Root cause

`scripts/prepublish-bundle-substrate.mjs` `copyHookBinaries` (L307-346) builds its copy set from `settings.json.hooks[].command` leaf filenames only. Helper scripts that other hooks `source` (like `trace-helper.sh`) and fragment directories (like `session-reflection.d/`) are silently skipped. Upstream public bassclef `v0.42.0` (SHA `f95f6bc1`) DOES ship those files under `dist/lite/.claude/hooks/`. The cli walker drops them at pack time.

## Fix

Replace the command-name filter with a recursive tree copy of `siblingRoot/dist/lite/.claude/hooks/`. Upstream already applies the tier filter at bundle time, so cli trusts the tree and copies it whole. Postflight assertion changes from `copiedHookCount === settingsDeclaredCount` to `copiedHookCount >= settingsDeclaredCount` AND every declared command has a matching binary.

## Value

Every cold adopter boots Claude cleanly on 1.0.3. The 1.0.1 → 1.0.2 → 1.0.3 crash cycle ends. Adopter trust in the cli line stabilizes.
