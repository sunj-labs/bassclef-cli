## Problem (≤500 chars)

Cold adopters running `npm install @thebassclef/lite@1.0.0 && bassclef init` today hit 24 hook-not-found errors per Claude Code prompt. Cli 1.0.0's walker copies the bundled substrate verbatim, but the walker was authored before dist/lite/ shipped hook binaries. Upstream v0.40.0 (cut 2026-09-13T20:40:20Z) now ships 24 hook binaries at dist/lite/.claude/hooks/*.sh. The walker must route each hook to its correct scope per settings.json prefix ($HOME vs $CLAUDE_PROJECT_DIR), preserve the executable bit, and refuse symlinks on both scopes. The adopter session must show zero errors.
