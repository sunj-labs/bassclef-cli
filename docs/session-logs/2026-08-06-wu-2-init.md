## Reviews caught

Two failures each subagent caught before they could ship:

**Ship-blocker** (architect-review, item 7): the settings.json
template assumed `../bassclef` sibling checkout + user-scope
sync hook. A cold-start adopter has neither. First-session Claude
Code config would break. FIX: minimal template with no sibling
assumption.

**Design gap** (architect-review, item 3): no manifest of what
init wrote + no version stamp inside emitted files. The sync
workunit would have been stuck reverse-engineering by content
hash. FIX: `.bassclef/init.manifest.json` with template versions +
per-file outcomes. Marker keys inside settings.json and
substrate.config.md front-matter for fallback discovery.
