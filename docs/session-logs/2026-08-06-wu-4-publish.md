## Ship-relevant fixes caught by review

**Architect-review DEFECT — missing workflow-path guard.** ADR-004
promised a Tier 0 test asserting `.github/workflows/publish.yml`
exists at the exact path. Without it, a future PR renaming the
workflow file passes CI green; publishing breaks silently on the
next tag. Fix: `tests/workflow-path.test.ts` with three assertions.

**Pattern-review CONCERN — tier-filter YAML parser too narrow.**
The regex only handled LF line endings, no BOM, no leading blank
line, no quoted values. A Windows-authored Markdown file with
`tier: upstream` in its frontmatter would silently ship. Fixed
before 0.0.2 tag; normalization is now semver-locked in ADR-004.

**Pattern-review CONCERN — missing allowlist test.** No test
exercised the FILE_ALLOWLIST branch that permits emails in
`package.json` and `LICENSE`. Added.
