## What shipped

`bassclef sync` — reads the manifest, detects change per file (four
cases: Current / NeedsUpdate / Edited / Deleted), applies updates
under two independent flags (`--force` for version updates,
`--replace-edits` for adopter-edit override). Safety contract in
ADR-003.

## Ship-relevant fixes caught by review

**Pattern-review DEFECT:** the Edited refusal message asserted "edited
by you" as fact. When the actual cause was an interrupted prior sync,
that message was wrong. Rewrote to name BOTH possible causes.

**Architect-review DEFECT:** content-hash normalization stripped only
CRLF. BOM addition on Windows save would have registered as an
adopter edit on a file the user never touched. Fixed BEFORE 0.0.2
tag — after tag, the algorithm is semver-locked.

**Structural CONCERN:** `src/lib/manifest-io.ts` was importing types
from `src/commands/init-templates/`. Extracted `Manifest` + `ManifestEntry`
+ `MANIFEST_SCHEMA_VERSION` into `src/lib/manifest-types.ts`. Init
template is now pure rendering.
