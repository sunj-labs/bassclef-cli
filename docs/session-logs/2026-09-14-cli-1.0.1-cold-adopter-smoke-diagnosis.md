## Root cause (thorough closure audit)

Cli walker did its job — copied every file the upstream bundle held. The bundle itself was incomplete. Audit of `dist/lite/.claude/hooks/` (24 files) against source repo `.claude/hooks/` (82 files):

**Hard-critical (crashes hooks):**
- `trace-helper.sh` — 5 bundled hooks source it with NO guard

**Missing entirely (whole subsystem silently disabled):**
- `session-reflection.d/*.sh` fragments — `session-reflection.sh:143` iterates the dir, dir doesn't exist in bundle, loop yields nothing. Orientation gate + active-goal surfacer + workflow-staleness check + deferred-actions surfacer all silent.

**Soft-guarded (functional loss, no crash):**
- `lib/state.sh` — 6 hooks probe it
- `lib/telemetry.sh` — 2 hooks probe it
- `lib/session-rescue.sh` — session-end probes it
- `lib/hook-heartbeat.sh` — 4 hooks probe two candidate paths
- `lib/hook-inject.sh` — 2 hooks probe two candidate paths

**Compounding cause** — `sunj-labs/bassclef` is PRIVATE (confirmed via `gh repo view`). Cold adopters have no auth. `bassclef-sync.sh:103` calls `git clone` which fails silently under `2>/dev/null`. Design assumed sync-clone would deliver missing files at runtime; on cold profiles that assumption never holds.
