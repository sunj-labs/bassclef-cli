## Lens applied — Linus (distribution-stability)

**Signature:** *"We do not break userspace."*

**Reads on this fix:** The v0.42.0 lite bundle is upstream's promise to every adopter. Cli's job is to ship that promise intact — every file the promise contains lands in the tarball. The current filter-by-command shape drops files the promise carries. That is a covert break of the userspace contract.

**Fold into fix:** The new `copyHookTreeRecursive` treats the sibling tree as authoritative — no cli-side filter. Any file upstream ships, cli ships. Adopter contract preserved.

**Ratchet:** Once 1.0.3 ships every file in the tree, adopters may source ANY of them. Removing a file later is a break requiring an ADR-031 compat window. Track this in the risk ledger.

## Lens applied — Cockburn (walking skeleton / architecture)

**Signature:** *"Build the walking skeleton first — the thinnest possible end-to-end slice that exercises every architectural layer."*

**Reads on this fix:** The Tier 0 fixture is the walking skeleton — sibling tree with `trace-helper.sh` + `session-reflection.d/fragment.sh` → cli walker → dist output → postflight OK. If the fixture end-to-end round-trip works, the fix works.

**Fold into fix:** Test list (in decomposition) starts with the walking-skeleton fixture test. Every downstream test extends one seam of that skeleton — one for symlinks, one for empty tree, one for missing declared command, etc.

**Ratchet:** The fixture must be committed alongside the fix, not built later. The RED commit lands the fixture + failing test; the GREEN commit lands the code.

## Lens applied — Nygard (stability patterns / circuit breaker)

**Signature:** *"Design for the day the far side is down."*

**Reads on this fix:** Postflight is the circuit breaker. Even if the walker had a bug (say, missed a file), postflight catches the settings.json declared-command → binary mismatch before `npm pack` ships. The fail-fast fires with a specific missing-name message, not a generic error.

**Fold into fix:** `assertDeclaredCommandsHaveBinaries` runs after every copy attempt. It cannot be skipped, deferred, or suppressed. The build dies loud with the exact command name that lacks a binary.

**Ratchet:** Never soften postflight to a WARN. It's the last line of defense; keep it BLOCK.

## Lens applied — Feathers (characterization tests)

**Signature:** *"Legacy code is code without tests. Add characterization tests to pin behavior before you change it."*

**Reads on this fix:** The old `copyHookBinaries` shipped for months without a test that would have caught the missing-helper class. First move: pin the CORRECT behavior in a test, then swap the implementation. The fixture at `tests/harness/fixtures/sibling-with-helpers/` characterizes the invariant — helpers survive the walk.

**Fold into fix:** RED commit lands the fixture + failing test. GREEN commit lands the code. The characterization tests survive the swap.

**Ratchet:** No untested change to `prepublish-bundle-substrate.mjs` from here forward. Any new invariant needs a fixture assertion first.

## Lens applied — Beck (test-first / Tier 0 strict-TDD)

**Signature:** *"Test-driven design. Red, green, refactor."*

**Reads on this fix:** `scripts/prepublish-bundle-substrate.mjs` is Tier 0 per `.claude/rules/testing-tier-config.md`. Every source edit must be preceded by a failing test. The mtime hook enforces this at commit time.

**Fold into fix:** Two-commit split — RED (tests + fixture; suite fails on the new tests) → GREEN (implementation; suite passes). The RED commit passes the mtime hook because tests are newer than the source they'll cover.

**Ratchet:** Never batch RED + GREEN into one commit. Reviewer must see the tests fail before they see the implementation pass.

## Composite recommendation

The five lenses converge on one shape:

- **Contract-first** (Linus + Feathers) — the fixture asserts the adopter contract before the code changes
- **Walking-skeleton first** (Cockburn + Beck) — the thinnest end-to-end slice ships as the first test
- **Fail-fast at the boundary** (Nygard) — postflight is the last check, not the first

The fix implements this in two commits — RED + GREEN — landing the test discipline in the same PR that lands the code discipline.
