## Findings

- NOTE: `shouldRefuseRoot` still lives in `src/commands/init.ts` and
  is imported cross-command by `sync.ts`. Not a defect but a natural
  candidate to move to `src/lib/` in a later WU.
- NOTE: The `$bassclef` marker recognizer uses substring match
  (`content.includes('"$bassclef"')`). Documented as intentional
  substring recognition. A file with `"$bassclef"` inside a
  comment or string literal would false-positive. Not currently
  a real risk; may tighten to JSON parse later.
- NOTE: No file lock. Two concurrent bassclef processes on the
  same target dir race the manifest. Documented in ADR-003
  single-writer assumption. Not a defect at two commands; a
  landmine to remember for a third writer.
- NOTE: Read is direct `readFileSync` — architect-review flagged
  the theoretical symlink-race denial-of-service class. ADR-003
  now restates the invariant as "no attacker-controlled path can
  be WRITTEN to" rather than "reads are safe."
- NOTE: Content-hash algorithm is semver-locked at 0.0.2. Any
  future normalization change is a MAJOR bump. ADR-003 pins the
  exact steps.
